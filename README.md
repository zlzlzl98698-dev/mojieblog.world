## 📖 项目简介 (Project Overview)

**魔戒博客 (mojieblog.world)** 是一套基于 **VitePress 1.6 + 简白主题 (Clean White) + Dark Network Observatory 监控级组件** 打造的高性能网络技术智库与商业流量转化站点。

站点秉承 **“数据真实、代码可测、架构可溯、拒绝虚构”** 的核心原则，系统性收录并深度跟踪了中文网络加速生态圈中 **42 家主流机场品牌**。所有评测与测试数据均在 **晚高峰 20:30 ~ 22:30 黄金拥堵时段** 由实验室千兆对等宽带探针实测采集，沉淀出涵盖延迟抖动、千兆吞吐带宽、底层加密协议效率、原生 IP 纯净度与工单 SLA 审计的全景数据库。

## ⚡ 核心功能与架构亮点 (Architecture Highlights)

### 1. 六大超级专题 SEO/GEO 知识导航矩阵
全站采用“一级栏目 → 二级专题 → 三级长尾 Spoke”的蜂巢式内链网络，各专题均具备独立的万字级支柱页与深度实操指南：
- 🎯 **[42 家机场终极推荐矩阵](/recommendations/)**：涵盖 8 元平民档、企业物理专线、Netflix 4K 解锁、Claude 3.5 原生 IP 及 147 永久买断包精准导购；
- 🔬 **[42 家深度性能横评实验室](/benchmarks/)**：晚高峰 Ping 延迟总排、千兆吞吐带宽压测、VLESS-Reality 协议效率、IP 欺诈分抽检及客服工单 SLA 审计；
- 🌐 **[免费节点大集合与安全防范白皮书](/free-nodes/)**：公共订阅可用性跟踪、中间人窃密 (MITM) 技术剖析、时间成本精算与双轨 CRO 拦截模型；
- ❓ **[科学上网百问百科 FAQ 智库](/faq/)**：节点全部超时 10 分钟自愈 SOP、底层专线原理、分流规则配置与 DNS 泄露防范（集成 Google `FAQPage` 结构化数据）；
- 🚨 **[机场跑路预警雷达与红黑榜曝光台](/risk-radar/)**：10 大致命跑路前兆自检清单、失联黑名单耻辱柱、5 分钟灾后恢复与支付宝/微信支付争议维权实操；
- 🎁 **[免费试用与无理由退款精选](/free-trial/)**：支持 1~3 天白嫖试用真实清单、24 小时无理由退款盘点、1 元尝鲜包横评与买断制升级路线。

### 2. Dark Network Observatory 可观测性组件系统
在清爽简白主题中完美融合了现代监控风格组件（`#0b1120` 深灰蓝底色 + 等宽代码字 + 霓虹绿状态高亮）：
- `<AirportCalculator />`：30 秒智能多维选型计算器（按场景、预算、设备实时动态匹配）；
- `<BrandFilter />`：42 家机场品牌库多条件实时过滤检索大厅（单行平整排版，彻底消除字词换行挤压）；
- `<SpeedtestCard />`：实验室原始千兆晚高峰测速仪表盘（香港 529 Mbps / 22ms 零丢包实测）；
- `<NetworkTopology />`：物理内网专线跨境数据传输链路拓扑解析；
- `<UnlockMatrix />`：海外流媒体与主流大模型（OpenAI / Claude / Gemini）原生解锁矩阵；
- `<AffiliateButton />`：100% 符合 Google 搜索规范的合规商业赞助外链组件（严格附带 `rel="nofollow sponsored noopener"` 与优惠码一键复制）。

### 3. 顶级 SEO / GEO 预防性基础设施
- **100% 静态预渲染 (SSG)**：所有核心文本、数据表与代码块在编译期固化于原始 HTML 源码中，不依赖客户端 JS 水合，对爬虫和 AI 搜索引擎友好；
- **全站动态 Canonical 矩阵**：109 个页面自引用绝对地址，与 `sitemap.xml` 精准对齐，杜绝重复内容过滤与权重分散；
- **多维度 JSON-LD Schema 体系**：全覆盖 `WebSite`、`CollectionPage`、`Article`、`BreadcrumbList`（3层面包屑）及 `FAQPage`；
- **外链合规化熔断**：Markdown-it 编译器层拦截出站链接，自动强制注入 `rel="nofollow sponsored noopener"`，阻断 Google Link Spam 惩罚风险；
- **搜索引擎多端友好**：标准 `robots.txt` 显式放行 Googlebot、bingbot、Baiduspider、yisouspider（神马/UC/夸克）。

## 🚀 本地开发与构建部署 (Getting Started)

### 1. 环境准备
确保本地安装有 **Node.js (>= 18.0.0)** 与 **npm**。

```bash
# 检查 Node 版本
node -v
```

### 2. 安装依赖
```bash
npm install
```

### 3. 启动本地实时热重载开发服务器
```bash
npm run docs:dev
```
访问 `http://localhost:5173/` 即可实时预览修改。

### 4. 生产环境静态打包与 Pagefind 索引生成
```bash
npm run docs:build
```
打包成功后，静态文件将输出至 `docs/.vitepress/dist`，并自动调用 Pagefind 建立全站离线全文检索索引（生成 109 个静态页面与 `sitemap.xml`）。

### 5. 本地预览生产构建产物
```bash
npm run docs:preview
```
