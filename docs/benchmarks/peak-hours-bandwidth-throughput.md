# 晚高峰千兆宽带吞吐量实测与超售率白皮书：揭秘机场背后的带宽抢占内幕

许多不良机场在售卖套餐时标榜“万兆带宽接入”、“无限制高速”，但一旦到了晚上 9 点，连 1080P YouTube 视频都无法流畅加载。根本原因就是**恶性超额售卖（Over-selling）**。

## 二、如何识别机场是否存在恶意超售？

1. **观察测速曲线平稳度**：真专线下载速度是一条笔直的横线；过度超售的机场曲线呈锯齿状剧烈上下跳动；
2. **测试 YouTube 统计信息**：在 YouTube 视频右键打开 Stats for nerds，观察 Connection Speed 是否稳定在 100,000 Kbps 以上。
