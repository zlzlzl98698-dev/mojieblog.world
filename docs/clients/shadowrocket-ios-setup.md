# Shadowrocket (小火箭) iOS 深度配置全攻略

**Shadowrocket**（常被国内用户亲切称为“小火箭”）是 iOS 生态中普及率最高、功能最均衡的规则代理客户端。它不仅支持几乎所有的现代网络代理协议，还具备出色的能耗比控制，能够在后台稳定保持长连接而不造成电池发热。

## 二、订阅导入的两种快速姿势

### 姿势一：Safari 浏览器一键唤醒导入
1. 在 iPhone 的 Safari 浏览器中登录您的[机场后台](/brands/)。
2. 找到「一键导入 Shadowrocket / 小火箭」按钮。
3. 点击后系统会弹出提示：“在 Shadowrocket 中打开？”，点击“打开”，客户端会自动完成订阅节点解析与加载。

### 姿势二：手动添加订阅链接
1. 复制机场提供的专用订阅 URL。
2. 打开 Shadowrocket，点击右上角的 **「+」号**。
3. 在「类型」一栏切换为 **「Subscribe」**。
4. 在「URL」栏中粘贴链接，备注填写服务商品牌名（如“光速云”），点击右上角「完成」。
5. 回到首页，向下滑动刷新列表即可载入全部节点。

## 三、全局路由与分流模式选择

在首页底部「全局路由」中，提供四种工作模式：
- **配置 (Config)**：**强烈推荐！** 遵循内置或远程规则，按域名与 IP 进行智能分流，国内网站直连，海外网站走代理。
- **代理 (Proxy)**：强制所有流量走选中的节点（仅用于特定测试）。
- **直连 (Direct)**：所有流量直连不走节点。
- **场景 (Scene)**：根据连接的 WiFi 名称（如公司内网、家庭网络）自动切换分流策略。

## 四、流媒体与 ChatGPT 原生解锁测试

小火箭内置了便捷的节点延迟与解锁探测工具：
1. 在首页点击节点列表，展开具体的节点详情。
2. 点击「连通性测试 (Ping)」，系统会显示各节点的 TCP 与 HTTP 往返耗时。
3. 搭配[《专题四：流媒体与 AI 原生解锁》](/topics/streaming-ai-unlock)中的住宅原生 IP 节点，即可在 iOS 官方 App 中畅享 Netflix 4K 与 ChatGPT 语音功能。
