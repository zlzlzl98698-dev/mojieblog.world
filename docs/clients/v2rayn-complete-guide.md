# v2rayN 多协议终极实操教程

**v2rayN** 是 Windows 平台资历最深、兼容性最广的开源代理客户端之一。它以极高的轻量化、免安装绿色便携、以及对前沿协议（如 **VLESS-Reality**、**Hysteria 2**、**TUIC**）的极速跟进适配而闻名，是技术型开发者和极客用户的利器。

---

## 一、下载解压与依赖环境

1. **官方 Release 地址**：
   - GitHub 官方仓库：`2dust/v2rayN`
   - 推荐下载带完整内核的整合包：`v2rayN-with-Core.zip`，避免手动下载 Xray/sing-box 核心文件的繁琐步骤。
2. **系统运行时依赖**：
   - Windows 10/11 系统需确保安装了 **Microsoft .NET 8.0 Desktop Runtime**（x64）。若运行报错提示缺失运行时，请前往微软官网免费安装。
3. **绿色解压**：
   - 严禁将解压目录放在 Windows 临时目录或受保护的 `Program Files` 目录下，推荐解压至非系统盘（如 `D:\Tools\v2rayN\`）。

---

## 二、订阅导入与节点批量测试

1. 登录您所使用的[机场服务商后台](/brands/)，复制 **V2Ray 订阅** 或 **通用订阅链接**。
2. 打开 v2rayN 主界面，点击顶部菜单栏的 **「订阅分组」 -> 「订阅分组设置」**。
3. 点击「添加」，输入备注名称（如“光速云主力”），在「可选地址(url)」处粘贴订阅链接，点击确定。
4. 返回主菜单，点击 **「订阅分组」 -> 「更新全部订阅(不通过代理)」**。
5. 节点加载完成后，按下快捷键 `Ctrl + A` 全选所有节点，右键点击选择 **「测试真实连接延迟(含速度)」**，列表将实时显示各节点的真实往返时间 (Ping) 与可用性。

---

## 三、系统代理模式设置

在 v2rayN 底部状态栏，找到系统代理切换选项：
- **自动配置系统代理**：开启后，桌面右下角托盘图标变为**红色**，表示系统代理已激活。
- **清除系统代理**：关闭代理，图标变为蓝色。
- **路由规则设置**：
  - 务必将路由切换为 **「绕过大陆 (Whitelist)」** 或自定义高级规则，防止微信、网银等国内流量走海外中转。

---

## 四、VLESS-Reality 与 Hysteria 2 高级配置

对于支持前沿协议的服务商，v2rayN 支持直接通过剪贴板导入节点分享链接（以 `vless://` 或 `hysteria2://` 开头）：
1. 复制单节点链接。
2. 在 v2rayN 主界面按下快捷键 `Ctrl + V`，即可一秒完成添加。
3. 双击节点可审查底层公钥 `Public Key`、短期域名 SNI 以及传输安全设置（XTLS / Reality）。
