## 二、实验室真实晚高峰（21:30）极限性能 PK

在晚高峰网络骨干网压力最大的时段，实验室对两者的香港与新加坡核心节点进行了连续 10 轮 Speedtest 压测取平均值：

```
┌─────────────────────────────────────────────────────────────────┐
│                    晚高峰核心节点测速对比 (千兆直连)             │
├──────────────┬────────────────────────┬─────────────────────────┤
│ 节点地区     │ 光速云 (实测下载 / 延迟)│ 暮光加速 (实测下载 / 延迟)│
├──────────────┼────────────────────────┼─────────────────────────┤
│ 香港 IEPL    │ 529 Mbps / 22 ms       │ 509 Mbps / 26 ms        │
├──────────────┼────────────────────────┼─────────────────────────┤
│ 新加坡 专线  │ 387 Mbps / 46 ms       │ 419 Mbps / 43 ms        │
├──────────────┼────────────────────────┼─────────────────────────┤
│ 日本东京     │ 135 Mbps / 57 ms       │ 150 Mbps / 53 ms        │
├──────────────┼────────────────────────┼─────────────────────────┤
│ 丢包率(Loss) │ 0.0 % (全程无丢包)     │ 0.0 % (全程无丢包)      │
└──────────────┴────────────────────────┴─────────────────────────┘
```

- **香港近端表现**：光速云以 **529 Mbps** 的微弱优势领先，且往返延迟低至惊人的 **22ms**，在网页加载首屏和视频拖动上几乎感觉不到任何代理的存在。
- **亚太综合表现**：两者在新加坡与日本节点上的表现旗鼓相当，网络抖动（Jitter）均控制在 2ms 级别，代表了国内 IEPL 专线的一流技术水准。

   两者均完整支持非自制剧播放（如《绝命毒师》全季 4K HDR 顺畅点亮）。
