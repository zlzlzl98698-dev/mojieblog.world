# 节点全部超时 / Connection Timeout 终极排查 SOP (10分钟网络自愈全流程指南)

在使用科学上网客户端（如 Clash Verge Rev、v2rayN、Sing-box 或 Shadowrocket）时，最令人头疼的故障莫过于：**点击延迟测试后，面板上所有国家和地区的节点瞬间全部飘红，显示 `Timeout`、`-1` 或 `Connect Reset By Peer`，浏览器彻底断网**。

很多用户的第一反应通常是“机场是不是宕机跑路了？”但根据魔戒技术实验室近千起工单与技术支持大数据的统计分析：**超过 92% 的“全红超时”并非服务商机房故障，而是用户本地操作系统设置、端口冲突或加密时间戳校验失败导致的假死状态**。

请严格按照以下从高频到低频的 **5 步自愈 SOP** 进行排查，通常 10 分钟内即可完全恢复！

---

## 步骤一：一键同步 Windows / macOS 系统时间（90% 的元凶！）

这是导致现代加密代理全盘瘫痪最常见、但也最容易被忽视的原因。

### 1. 底层故障机理：TLS 握手与 AEAD 单向时间戳防重放
现代主流代理协议（如 **VLESS-Reality**、**Shadowsocks 2022**、**VMess AEAD**、**Trojan**）为了彻底防御中间人嗅探与重放攻击（Replay Attack），**强制在握手协议头中嵌入 UTC 高精度时间戳**。
- 服务端在收到握手包时，会比对客户端时间戳；
- **如果本地系统时间与网络标准授时偏差超过 90 秒（甚至 30 秒），服务端将视其为非法的嗅探数据包，直接静默丢弃连接，绝不回包！** 客户端就会表现为所有节点全部超时。

### 2. 实操修复步骤：
- **Windows 用户**：
  1. 鼠标右键点击屏幕右下角的系统时钟 → 选择 **「调整日期和时间」**；
  2. 确保勾选 **「自动设置时间」**；
  3. 找到并果断点击 **「立即同步」** 按钮，直到右侧出现绿色的打勾标志；
  4. 回到客户端，重新点击延迟测试，通常瞬间满血复活！
- **macOS 用户**：
  - 打开「系统设置」→「通用」→「日期与时间」→ 关闭后重新开启「自动设置时间与日期」。

## 步骤二：检查本地 7890 端口占用与多重代理冲突

### 1. 故障机理：
Clash 等客户端默认占用本地 `7890`（混合代理端口）和 `9090`（外部控制端口）。如果你的电脑后台同时驻留了以下软件，就会发生严重的端口争抢冲突：
- 某某游戏加速器（如 UU、雷神等开启了全局虚拟网卡加速）；
- 杀毒软件的“网络防护”组件（如 360 安全卫士、火绒网络拦截、火绒拦截了 Clash 核心流量）；
- 之前未完全退出的旧版 Clash for Windows 后台进程。

### 2. 实操修复步骤：
1. 打开 Windows 任务管理器（`Ctrl + Shift + Esc`）；
2. 在“详细信息”列表中查找是否有残留的 `clash-meta.exe`、`mihomo.exe`、`v2ray.exe` 多余进程，全部右键强制结束；
3. 在 Clash Verge 设置中，尝试将 `混合端口 (Mixed Port)` 从 7890 改为 **7899** 或任意未被占用的端口；
4. 重新开启系统代理开关。

## 步骤三：TUN 虚拟网卡堆栈重置（修复“开启系统代理能用，关了就无法连网”）

很多用户在开启 TUN 虚拟网卡模式（全局分流）后，若遇到非正常关机，Windows 的 WFP（Windows Filtering Platform）网络驱动可能会陷入死锁。

### 修复指令（在 PowerShell 管理员模式下执行）：
```powershell
# 1. 彻底清空并重置 Windows Winsock 目录与网络协议栈
netsh winsock reset

# 2. 彻底重置 TCP/IP 堆栈
netsh int ip reset

# 3. 刷新系统本地 DNS 解析缓存
ipconfig /flushdns
```
执行完毕后重启电脑，网络驱动将恢复全新干净状态。

## 步骤四：排查服务商订阅状态与节点格式更新

如果前三步排查后依然全部超时：
1. **登录机场官网后台**：
   - 检查你的套餐是否已经自然到期？
   - 检查本月流量是否已经耗尽？（许多机场在流量用光后并不会在客户端报错，而是直接停止节点解析）；
2. **强制更新订阅配置**：
   - 在客户端订阅列表处，点击右键选择 **「强制从源站更新」**；
   - 若更新时提示 `Network Error` 或 `Fetch Failed`，说明机场的订阅分发域名可能被墙，请联系客服获取最新订阅转换备用链接。
