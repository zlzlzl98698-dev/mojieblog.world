# 规则分流 (Rule) VS 全局模式 (Global) VS 直连模式深度辨析与分流避坑指南

许多新手在安装并开启科学上网软件后，经常会遇到以下奇怪的现象：
- *“为什么开了代理后，刷国内抖音、淘宝变得很卡，微信消息偶尔延迟甚至弹窗提示‘异地登录警告’？”*
- *“为什么我的月付流量用得特别快，明明没怎么看油管，几天几十个 G 就没了？”*

这绝大多数是由于**工作模式（Mode）选择错误**导致的。在主流客户端（如 Clash Verge Rev、v2rayN、Shadowrocket）中，通常提供了 **规则分流 (Rule)**、**全局代理 (Global)** 与 **直连模式 (Direct)** 三大运行模式。

本文将为您彻底厘清三种模式的运行逻辑与最佳日常配置策略。

---

## 一、三大分流模式核心机理对照表

| 模式名称 | 运行机理与流量流向 | 消耗代理流量吗？ | 适用场景 | 优缺点深度分析 |
| :--- | :--- | :--- | :--- | :--- |
| **规则分流 (Rule / 智能分流)** ⭐ | 客户端根据规则库（GeoIP/Domain）智能识别：**国内直连，海外走代理** | 仅访问海外受限网站时消耗 | **99% 的全天候日常使用场景** | **国内访问不减速，省流量，微信不报异地登录，免去频繁开关软件之苦** |
| **全局代理 (Global / 强制代理)** | **电脑/手机的所有网络请求，无条件全部强行打包走海外代理出口** | 访问任何网站（包含国内百度、微信）均疯狂扣除流量 | 仅在个别冷门海外网站规则库遗漏、或特定调试时临时使用 | **严重消耗代理流量、国内网站巨卡、国内 App 频繁触发异地登录人脸识别** |
| **直连模式 (Direct / 完全放行)** | 客户端仅充当透明转发器，所有流量都不走代理服务器 | 完全不消耗代理流量 | 临时完全停用代理功能，等同于关闭软件 | 无法访问任何海外受限站点 |

## 二、为什么强力推荐始终保持在【规则分流 (Rule)】模式？

### 1. 保障国内生态访问速度与本地 CDN 加速
当你访问淘宝、京东或网易云音乐时，这些平台在全国部署了数以万计的边缘 CDN 缓存节点。在【规则分流】模式下，你的请求直接访问离你最近的本地机房，毫秒级秒开；若误开【全局模式】，你的请求会先飞去香港机房再绕回国内，产生几百毫秒的严重延迟。

### 2. 避免国内 App 频繁触发“异地登录风控”
微信、支付宝、小红书等超级应用具备严格的安全风控模型。如果检测到你的 IP 地址在几秒内从“北京市朝阳区”突变为“中国香港葵涌机房”或“美国洛杉矶”，系统会误判你的账号被黑客盗取，强制弹窗要求短信或人脸验证，严重者甚至直接冻结账号！

### 3. 最大化节省宝贵的套餐流量
很多用户的机场套餐每月只有几十 G。如果在全局模式下后台挂着代理去下载国内某 20GB 的游戏补丁，那么一眨眼功夫你的月付额度就会被彻底清空！

## 三、进阶分流规则配置建议（针对专业极客）

在 Clash Verge Rev 中，优秀的规则集（Rule Provider）通常基于 Loyalsoldier 或 ACL4SSR 规则库。建议在配置文件中确认以下规则顺序：

```yaml
# 核心规则执行优先级示意
rules:
  # 1. 核心大模型与流媒体强制走特定代理出口
  - GEOSITE,openai,🤖 AI Productivity
  - GEOSITE,netflix,🎬 Streaming Media
  # 2. 常见海外受限域名走默认代理
  - GEOIP,telegram,✈️ Telegram
  - GEOSITE,geolocation-!cn,🚀 Proxy Group
  # 3. 国内所有域名与 IP 强制直连
  - GEOIP,CN,DIRECT
  - GEOSITE,cn,DIRECT
  # 4. 漏网之鱼兜底规则
  - MATCH,🚀 Proxy Group
```
