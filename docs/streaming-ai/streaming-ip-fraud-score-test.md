在挑选[科学上网机场](/brands/)时，服务商的宣传文案往往充满“顶级原生”、“4K秒开”、“极速防封”等高调辞藻。然而，作为具备技术辨别能力的极客用户，我们绝不能只听信单方面的口号，而应该依靠**权威可观测性工具，亲手检测节点的 IP 纯净度与欺诈分（Fraud Score）**。

## 一、核心概念：什么是 IP 欺诈分 (Fraud Score)？

**Scamalytics** 和 **IPinfo** 是全球各大跨国互联网企业（包括 OpenAI、PayPal、Stripe、Netflix、Google）普遍采用的反欺诈风控数据库。

它们通过分析全球数十亿次网络连接，为每一个 IPv4 和 IPv6 地址计算一个从 **0 到 100** 的风险评分：

```
┌─────────────────────────────────────────────────────────────────┐
│                    Scamalytics 风险评级对照表                   │
├──────────────┬──────────────────┬───────────────────────────────┤
│ 欺诈分区间   │ 风险等级         │ 典型表现与访问限制            │
├──────────────┼──────────────────┼───────────────────────────────┤
│ 0 ~ 15 分    │ Very Low Risk    │ 原生极度纯净，ChatGPT/流媒体全通│
├──────────────┼──────────────────┼───────────────────────────────┤
│ 16 ~ 30 分   │ Low Risk         │ 正常商业光纤，可稳定用于日常办公│
├──────────────┼──────────────────┼───────────────────────────────┤
│ 31 ~ 60 分   │ Medium Risk      │ 普通机房 IP，频繁弹出人机验证码 │
├──────────────┼──────────────────┼───────────────────────────────┤
│ 61 ~ 100 分  │ High / Very High │ 严重污染黑名单，直拒访问与支付│
└──────────────┴──────────────────┴───────────────────────────────┘
```

## 二、三步实测您的节点 IP 纯净度

### 第一步：打开权威反欺诈检测平台
在开启代理的情况下，在浏览器中打开：
- **Scamalytics 官方测试站**：`scamalytics.com/ip`
- 系统会自动抓取您当前的代理出口 IP，并输出完整的风控报告。

### 第二步：核验核心参数指标
重点关注报告中的以下几个字段：
1. **Fraud Score**：越低越好，**低于 20 分**属于优质梯队。
2. **IP Type (类型)**：
   - 若显示为 `Data Center / Web Hosting`，说明是普通机房托管机器。
   - 若显示为 `ISP` 或 `Residential`，说明是极其珍贵的**家庭宽带原生住宅 IP**。
3. **Anonymity (匿名度)**：检查是否已被标记为公共 Tor 节点或公开 VPN 节点。

### 第三步：核查 WebRTC 与 DNS 一致性
访问 `browserleaks.com/ip`，确认：
- 您的 WebRTC 地址没有泄露国内真实内网 IP。
- 您的 DNS 服务器归属地与当前出口节点保持在同一个国家/大区。
